# Jade Veil · 玉幕 — 接入说明

把本压缩包里的文件按相同路径放进 `yokiyuzi.github.io` 仓库根目录即可：

| 文件 | 作用 |
|---|---|
| `js/jade-veil.js` | 3D 场景本体（幕布、玉纹 shader、金线、月亮、相机路径） |
| `js/jade-veil-boot.js` | 首页启动脚本：插入 canvas、阅读遮罩、进度线、文字滑入 |
| `css/jade-veil.css` | 只在 `html.veil-on` 时生效的样式；WebGL 不可用时页面保持原样 |
| `js/vendor/three.module.min.js` | three.js r170（MIT），同源加载，不依赖 CDN |
| `index.html` | 只多了 3 行：一个 stylesheet、一个 importmap、一个 module script |

## 常用调节点（都在 `js/jade-veil.js`）

- `STOPS`：每个章节对应的相机机位 `[眼睛位置, 看向的点, 视角 fov, 画面右移量]`。
- `curtain({...})`：每块幕布的位置、宽度、朝向、颜色，以及 `open: [开始, 结束]`——它在第几章被拉开。
- `U.uFlow.value += dt * (0.35 + vel * 6.0)`：0.35 是静止时玉纹的流速，6.0 是滚轮带动流速的力度。
- `wTarget = Math.min(1.4, Math.abs(vel) * 2.2)`：滚动产生的“风”有多大。
- `uv = vLocal*0.085`（片元着色器）：玉纹的尺度，越小纹路越大越柔。

## 性能与无障碍

- 设备像素比上限 1.75；帧时间偏长时自动降分辨率；静止时降到 30fps；页面不可见时停止渲染。
- `prefers-reduced-motion`：不播放开场、不随滚动加风、无惯性。
- 无 WebGL：不加 `veil-on`，原来的静态玉石插画照常显示。

## 仓库接入说明

- 保留现有随机语录、导航、文章列表和静态插画；仅在首页加载玉幕。
- 自适应清晰度仅采样非静止帧，避免把主动限制到 30fps 误判为性能不足。
- 切换标签页时取消待执行的动画帧，返回后恢复；减少动态效果时章节导航直接跳转。
- 打印时关闭画布和文字入场效果，保证所有章节可见。
- Three.js r170 和噪声算法的 MIT 许可随代码保存在 `js/vendor/three-LICENSE.txt` 与 `js/vendor/webgl-noise-LICENSE.txt`。

## v2「描金」

新增层次与可调参数（都在 `js/jade-veil.js`）：

- **碎金**：幕布撕边上的金箔壳会断成碎片，有的地方堆得厚，有的地方几乎没有。
  - `band = (0.05 + 0.50*…)*uLeaf`：金箔壳最宽能伸进玉面多远。
  - 每块幕布的 `leaf:` 参数（默认 1，0 表示不贴金）。
  - 玉纹金脉旁也会散落金屑：`nearVein*0.42` 控制多少。
  - 深玉圆盘的边缘会碎成金片，盘面里悬着少量金点：`DISC_FS` 里的 `0.012`。
- **飘落的金箔**：`NF`（桌面 340 / 手机 150）。每片是一片撕开、揉皱的金箔，翻转时会闪光；滚得越快，转得越快。
- **线条**：线条做成了笔触。两头收尖，中间有粗有细，还会像水里的丝线一样起伏。每组是一根主笔加几根游丝，沿途时而散开、时而收拢。
  - `bundle(points, { n, gap, width, nodes, amp, freq, dry, draw })`：`nodes` 是收拢点的数量；`dry` 是飞白的程度。
  - 轨道改成一金一浅金的双线，前粗后细。小金珠后面拖一段亮尾。
- **云**：`mist(x, y, z, 宽, 高, { opacity, rim })`。描金云纹的金色轮廓会断续出现，`rim` 控制轮廓强度。
- **月晕**：`HALO_FS` 里有光晕和两道细环。
- **玉的透光与丝光**：月亮在幕布后面时，玉会透出光（`uGlow`）；褶皱上有一道顺着往下走的丝绸高光。
- **双金边**：每条撕边都有一道金边，内侧再有一道细线，呼应 logo 的双环。

性能：v2 比 v1 重一些。原有的自动降分辨率和静止时 30fps 照常生效。

## v3「风 · 夜 · 印」更新

需要替换或新增的文件（`index.html` 不用改）：

- 替换 `js/jade-veil.js`：已经包含 v2 的全部内容。
- 替换 `js/jade-veil-boot.js` 和 `css/jade-veil.css`。
- 新增 `js/jade-seal.js`：印章，字形已经内嵌，不需要请求任何字体。
- 新增 `js/vendor/noto-serif-cjk-OFL.txt`：印章所用字形的开源许可。

**风（光标）**
- 光标划过时，幕布上会荡开一圈圈涟漪。最多同时存在 6 圈，每走过约 70px 生成一圈。光标正下方的布会轻轻让开。
- 光标附近的线条会颤动起来。
- 光标后面会拖着一小团打旋的金箔。附近飘着的金箔也会被卷进旋涡，风停后慢慢散开、落下。
- 光标在左侧阅读栏上方时，这团金箔会收起来，不干扰阅读。手机上没有光标，这团金箔不启用。
- 可调参数：`addImpulse(…)` 的触发距离 `travel > 70`、`WAKE_VS` 里旋涡的半径和大小、`NW`（金箔数量）。

**夜（昼 · 夜 切换）**
- 导航栏里多了「昼 · 夜」切换，只作用于首页。配色用的是 `style.css` 里原有的暗色主题，背景是 `#071e1a`。
- 夜间时：月亮成为光源，带一圈更宽的月晕；玉幕变暗，有月光从背后透过来；金边和金箔更醒目；云变成墨青色；远处出现星星。切换时有约一秒半的渐变。
- 访客的选择会保存在 `localStorage`。默认值在 `js/jade-veil-boot.js` 开头的 `NIGHT_DEFAULT`：
  - `'day'`：默认白天。
  - `'night'`：默认夜间。
  - `'system'`：跟随访客的系统设置。
  - `'clock'`：19:00 到 06:00 自动夜间。

**印（落款）**
- 滚到最后一章时，一方朱砂印章会盖在这一章文字的末尾，旁边写着当年的干支和季节。印落下时，会往画面里送出一圈涟漪和一团金箔，进度线的最后一个点也会变成朱红。
- 印文在 `js/jade-veil-boot.js` 开头的 `SEAL_TEXT` 里修改，默认是「格物致知」。印章可以是 1、2 或 4 个字，4 个字时按传统顺序，先读右列再读左列。
  - 换成内嵌字形里没有的字时，会改用访客系统里的宋体。
  - 想继续用同一套字形，需要重新从 Noto Serif CJK SC 里裁出这些字。
- 年份和季节按访问当天自动计算，比如 2026 年 11 月显示「丙午冬」。年份在立春（约 2 月 4 日）更替。

**性能**
- v3 只比 v2 多了一点：涟漪计算在顶点着色器里做；金箔旋涡只有 72 片；星星只在夜间绘制。
- 原有的自动降分辨率照常生效。

## v3 仓库适配
