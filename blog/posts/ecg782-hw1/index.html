Three estimation-theory problems: (1) bias and variance of the biased sample-variance estimator $\hat\sigma^2$ for IID $\mathcal{N}(0,\sigma^2)$ data, and its behavior as $N\to\infty$; (2) a derivation that the sample mean $\hat A$ is exactly $\mathcal{N}(A,\sigma^2/N)$; (3) the minimum-variance linear unbiased estimator among linear estimators $\hat A=\sum_n a_n x[n]$, obtained via Lagrange multipliers.

Problem 1

The data $\{x[0],x[1],\ldots,x[N-1]\}$ are observed, where the $x[n]$'s are independent and identically distributed (IID) as $\mathcal{N}(0,\sigma^2)$. We wish to estimate the variance $\sigma^2$ as

$$\hat\sigma^2 = \frac{1}{N}\sum_{n=0}^{N-1} x^2[n].$$

Is this an unbiased estimator? Find the variance of $\hat\sigma^2$ and examine what happens as $N\to\infty$.

SOLUTION

Consider the estimator $\hat\sigma^2=\frac{1}{N}\sum_{n=0}^{N-1}x^2[n]$, with $x[n]\sim\mathcal{N}(0,\sigma^2)$. To determine whether it is unbiased, note that

$$E[x^2[n]] = \operatorname{Var}(x[n]) + \bigl(E[x[n]]\bigr)^2 = \sigma^2.$$

Therefore,

$$E[\hat\sigma^2] = \frac{1}{N}\sum_{n=0}^{N-1} E[x^2[n]] = \sigma^2.$$
Unbiasedness $\hat\sigma^2$ is an unbiased estimator of $\sigma^2$.

To calculate its variance, use the fourth-moment identity for a zero-mean Gaussian random variable, $E[x^4[n]]=3\sigma^4$. It follows that

$$\operatorname{Var}(x^2[n]) = E[x^4[n]] - \bigl(E[x^2[n]]\bigr)^2 = 3\sigma^4 - \sigma^4 = 2\sigma^4.$$

Since the observations are independent, their squares are also independent. Hence,

$$\operatorname{Var}(\hat\sigma^2) = \frac{1}{N^2}\sum_{n=0}^{N-1}\operatorname{Var}(x^2[n]) = \frac{1}{N^2}(N\cdot 2\sigma^4) = \frac{2\sigma^4}{N}.$$

As $N\to\infty$, the variance approaches zero. Since the estimator is unbiased, its mean squared error satisfies

$$E\bigl[(\hat\sigma^2-\sigma^2)^2\bigr] = \frac{2\sigma^4}{N} \longrightarrow 0.$$

Therefore $\hat\sigma^2$ converges to $\sigma^2$ in mean square. Furthermore, by Chebyshev's inequality, for every $\varepsilon>0$,

$$P\bigl(|\hat\sigma^2-\sigma^2|\ge\varepsilon\bigr) \le \frac{2\sigma^4}{N\varepsilon^2} \longrightarrow 0.$$
Consistency: $\hat\sigma^2$ is consistent. The denominator is $N$, rather than $N-1$, because the population mean is known to be zero.

Problem 2

Prove that the PDF of $\hat A$ given in Example 2.1 is $\mathcal{N}(A,\sigma^2/N)$.

SOLUTION

In Problem 1, the observations follow the model

$$x[n] = A + w[n], \qquad n=0,1,\ldots,N-1,$$

where $A$ is an unknown constant and $w[n]\sim\mathcal{N}(0,\sigma^2)$. The estimator is the sample mean:

$$\hat A = \frac{1}{N}\sum_{n=0}^{N-1} x[n] = A + \frac{1}{N}\sum_{n=0}^{N-1} w[n].$$

A linear combination of independent Gaussian random variables is Gaussian. Consequently, $\hat A$ is Gaussian, and its distribution is completely determined by its mean and variance.

Its mean is

$$E[\hat A] = A + \frac{1}{N}\sum_{n=0}^{N-1} E[w[n]] = A.$$

Using the independence of the noise samples, its variance is

$$\operatorname{Var}(\hat A) = \operatorname{Var}\!\left(\frac{1}{N}\sum_{n=0}^{N-1} w[n]\right) = \frac{1}{N^2}\sum_{n=0}^{N-1}\operatorname{Var}(w[n]) = \frac{N\sigma^2}{N^2} = \frac{\sigma^2}{N}.$$

Therefore,

$$\hat A \sim \mathcal{N}\!\left(A,\frac{\sigma^2}{N}\right).$$
Probability density function $$f_{\hat A}(a;A) = \sqrt{\frac{N}{2\pi\sigma^2}}\exp\!\left[-\frac{N(a-A)^2}{2\sigma^2}\right], \quad -\infty

This distribution is exact for every $N$; it does not require a central-limit-theorem approximation. Strictly speaking, the problem concerns the PDF of $\hat A$, since $A$ is a fixed unknown parameter.

Problem 3

For the problem described in Example 2.1, the more general estimator

$$\hat A = \sum_{n=0}^{N-1} a_n\, x[n]$$

is proposed. Find the $a_n$'s so that the estimator is unbiased and the variance is minimized. Hint: use Lagrange multipliers with unbiasedness as the constraint equation.

SOLUTION

Under the same observation model, consider the linear estimator

$$\hat A = \sum_{n=0}^{N-1} a_n\, x[n],$$

where the $a_n$'s are deterministic coefficients.

First, impose the unbiasedness requirement. Since $E[x[n]]=A$,

$$E[\hat A] = \sum_{n=0}^{N-1} a_n\, E[x[n]] = A\sum_{n=0}^{N-1} a_n.$$

For this expectation to equal $A$ for every possible value of $A$, the coefficients must satisfy $\sum_{n=0}^{N-1} a_n = 1$. Because the observations are independent and each has variance $\sigma^2$,

$$\operatorname{Var}(\hat A) = \sum_{n=0}^{N-1} a_n^2 \operatorname{Var}(x[n]) = \sigma^2 \sum_{n=0}^{N-1} a_n^2.$$

The optimization problem is therefore

$$\min_{\{a_n\}} \ \sigma^2 \sum_{n=0}^{N-1} a_n^2 \quad \text{subject to} \quad \sum_{n=0}^{N-1} a_n = 1.$$

Introduce the Lagrangian

$$\mathcal{L}(a_0,\ldots,a_{N-1},\lambda) = \sigma^2\sum_{n=0}^{N-1} a_n^2 + \lambda\!\left(\sum_{n=0}^{N-1} a_n - 1\right).$$

Differentiating with respect to each coefficient and setting the derivative to zero gives

$$\frac{\partial\mathcal{L}}{\partial a_n} = 2\sigma^2 a_n + \lambda = 0 \ \implies \ a_n = -\frac{\lambda}{2\sigma^2},$$

so all coefficients must be equal. Substituting into the constraint yields

$$-\frac{N\lambda}{2\sigma^2} = 1 \ \implies \ \lambda = -\frac{2\sigma^2}{N}.$$

Therefore,

$$a_n = \frac{1}{N}, \qquad n=0,1,\ldots,N-1.$$

For $\sigma^2>0$, the objective function is strictly convex and the constraint is linear, so this solution is the unique global minimum.

Minimum-variance linear unbiased estimator $$\hat A_{\text{opt}} = \frac{1}{N}\sum_{n=0}^{N-1} x[n], \qquad \operatorname{Var}(\hat A_{\text{opt}}) = \sigma^2\sum_{n=0}^{N-1}\left(\frac{1}{N}\right)^2 = \frac{\sigma^2}{N}.$$
Conclusion: Among all linear unbiased estimators, the sample mean minimizes variance — with $\operatorname{Var}(\hat A_{\text{opt}})=\sigma^2/N$, matching the exact distribution derived in Problem 2.
