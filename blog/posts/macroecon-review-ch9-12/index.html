第九章 · 宏观经济的基本指标及其衡量

1. GDP（国内生产总值）

GDP 是指一定时期内在一国境内生产的所有最终产品与服务的市场价值总和。 一国经济从对产品和服务需求的角度可划分为四个部门：家庭部门的消费（$C$）、企业部门的投资（$I$）、 政府部门的购买（$G$）和国外部门的净出口（出口 $X$ 减进口 $M$，$NX = X-M$）。

$$\text{GDP} = C + I + G + NX$$

2. NNP、NI、GNP

NNP（国民生产净值）是从 GNP 中减去资本折旧；NI（国民收入）是与国民净产值近似相等的收入衡量指标：

$$\text{NNP} = \text{GNP} - \text{折旧}, \qquad \text{NI} = \text{NNP} - \text{统计误差}$$

GNP（国民生产总值）：一个特定经济体的公民拥有的生产要素所生产的产出的市场价值：

$$\text{GNP} = \text{GDP} + \text{来自国外的要素报酬} - \text{支付给国外的要素报酬}$$

3. 物价水平：CPI 与 GDP 平减指数

CPI（消费价格指数）：对商品篮子中的价格变动和消费者支出进行调查和记录：

$$\text{CPI} = \frac{\text{现期价格下"商品篮子"的费用额}}{\text{基期价格下"商品篮子"的费用额}} \times 100$$

GDP 平减指数反映名义 GDP 与实际 GDP 之间因价格水平变化而产生的差异：

$$\text{GDP 平减指数} = \frac{\text{名义 GDP}}{\text{实际 GDP}} \times 100$$

4. 通货膨胀

通货膨胀是指一个经济体在一定时期内价格水平普遍、持续上升的情况，其程度用通货膨胀率反映：

$$\pi_t = \frac{P_t - P_{t-1}}{P_{t-1}} \times 100\%$$

5. 就业与失业指标

家庭调查中，每个家庭的每个成年人被归为以下三类之一：就业者、失业者、不属于劳动力者。

$$\text{劳动人数} = \text{就业人数} + \text{失业人数}$$ $$\text{失业率} = \frac{\text{失业人数}}{\text{劳动人数}} \times 100\%, \qquad \text{就业率} = \frac{\text{就业人数}}{\text{劳动人数}} \times 100\%$$ $$\text{劳动参与率} = \frac{\text{劳动力人数}}{\text{劳动年龄人口数}} \times 100\%$$

失业主要分为三种类型：摩擦性失业、结构性失业和周期性失业。

滞涨（Stagflation）： 经济体出现高失业率（停滞）与高通货膨胀率并存的现象 （美国 1974–75 年 / 1980–81 年为典型案例）。

第十章 · 国民收入的决定：收入支出模型

1. 封闭经济的循环流程

家庭通过向生产要素市场提供劳动获得收入，再以购买消费产品和服务、以及向政府纳税的形式支出其收入， 并通过货币市场进行储蓄；企业通过出售产品与服务获得收入，再以购买生产要素来支出其收入； 政府通过向企业和家庭征税获得收入，再以政府购买来支出其收入。同时，出于各自不同的需要， 家庭、企业、政府都会通过货币市场进行借贷。

2. 消费函数与储蓄函数（两部门·家庭部门）

消费函数 $C=C(Y)$（$Y$ 为可支配收入）：

  • APC（平均消费倾向）：消费曲线上任意一点与原点连线的斜率 $$\text{APC} = \frac{C}{Y}$$
  • MPC（边际消费倾向）：增加的消费额与增加的可支配收入额之比，即 $C$ 函数在该点的斜率 $$\text{MPC} = \frac{\Delta C}{\Delta Y} = \frac{\mathrm{d}C}{\mathrm{d}Y}$$

储蓄函数 $S=S(Y)$，$S = Y - C$：

  • APS（平均储蓄倾向）：$\text{APS} = \dfrac{S}{Y}$
  • MPS（边际储蓄倾向）：$\text{MPS} = \dfrac{\Delta S}{\Delta Y}$

设消费函数为 $C = \alpha + \beta Y$，则储蓄函数可推导为：

$$S = Y - C = Y - (\alpha + \beta Y) = -\alpha + (1-\beta)Y$$
APC 和 MPC 都随收入增加而递减，且 APC > MPC；
APC + APS ≡ 1，MPC + MPS ≡ 1（恒等关系）。

影响消费的其他因素：① 利率（提高利率刺激储蓄，减少消费）；② 价格水平（货币收入与实际购买力的对比）； ③ 收入分配（高收入家庭消费倾向较小，低收入家庭消费倾向较大）；④ 预期。

3. 投资（两部门·企业部门）

企业的主要支出是投资。投资需求是总需求中的重要部分，且比消费需求更具变化性， 因而对均衡国民收入的影响也更大。

  • MEC（资本边际效率）：一种贴现率，恰好使一项资本品在使用期内各预期收益的现值之和 等于这项资本的供给价格（或重置成本）： $$R_n = R_0(1+r)^n$$
  • MEI（资本边际效率曲线）：市场利率越低，投资需求量越大；企业根据不同市场利率 选择不同项目，期待不同收益。

影响预期收益的因素：① 对投资项目产品的需求预期；② 产品成本；③ 投资税抵免；④ 投资风险； ⑤ 融资条件对投资需求的影响。

利率分为名义利率（借贷双方按约定支付的利率）和实际利率 （约等于名义利率减去通货膨胀率）。企业是否对新的实物资本进行投资，取决于预期利润与借入资金的成本。

托宾 q 理论：

$$q = \frac{\text{企业股票的市场价值}}{\text{新建企业的成本（重置成本）}}$$

当 $q<1$ 时，买旧企业比新建更便宜，投资需求偏弱；股票价格上升、$q$ 上升时，投资会相应增加。

4. 政府部门（三部门经济）

政府需求分为政府消费需求和政府投资需求。政府对社会总需求的影响途径： ① 直接购买支出；② 税收；③ 转移支付；④ 制度和政策。

5. 乘数

乘数是凯恩斯主义理论中，强调总需求变化对均衡国民收入产生进一步（放大）影响的重要机制。

投资乘数（国民收入变动量与引起该变化的初始投资支出之比）：

$$k = \frac{1}{1-\text{MPC}} = \frac{1}{\text{MPS}}$$

三部门经济中，总支出 $Y = C+I+G = \alpha + \beta(Y-T) + I + G$，解得均衡收入：

$$Y = \frac{\alpha + I + G - \beta T}{1-\beta}$$
乘数定义公式
政府购买支出乘数$K_G = \Delta Y/\Delta G$$\dfrac{1}{1-\beta}$
税收乘数$K_T = \Delta Y/\Delta T$$\dfrac{-\beta}{1-\beta}$
政府转移支付乘数$K_{tr} = \Delta Y/\Delta Tr$$\dfrac{\beta}{1-\beta}$

6. 判断题与要点归纳

  • 收入很低时，平均消费倾向可能大于 1，且平均消费倾向总为正数；平均消费倾向不一定总是大于边际消费倾向（在收入很低的极端情形下例外）。
  • 投资和政府的支出是自发性支出时，属于外生变量。
  • 影响乘数发挥作用大小的因素：经济体中过剩生产能力的大小、投资与储蓄决定的相对独立程度、 货币供给是否适应支出的需要、经济体中部分资源"约束瓶颈"程度的大小。
  • 以凯恩斯经济理论为基础的短期经济波动理论涉及的市场包括：货币市场、劳动市场、产品市场、国际市场。
  • 边际消费倾向本身不会直接增加或减少 GDP；可支配收入的增加会使边际消费倾向递减。

原始笔记将"自发性支出对应的变量类型"记为"内生变量"，但按标准定义，自发性（autonomous）支出是不随收入 $Y$ 变动的外生给定量，属于外生变量——此处按标准表述订正，供复习时留意。

例题 10-1 · 三部门经济乘数

已知消费函数为 $C = 100+0.9Y_d$（$Y_d$ 为可支配收入），投资 $I=300$，政府购买支出 $G=160$， 税收 $T=0.2Y$。

  1. 试求均衡的国民收入水平；
  2. 试求政府购买支出乘数；
  3. 若政府购买支出增加到 300，新的均衡国民收入是多少？
解答

(1) $C = 100+0.9Y_d = 100+0.9(1-0.2)Y = 100+0.72Y$。计划支出 $AE=C+I+G=560+0.72Y$，由均衡条件 $AE=Y$ 得 $Y^*=2000$。
重点：区分可支配收入是否需要先减去税收。

(2) $$K_G = \frac{1}{1-\beta(1-t)} = \frac{1}{0.28} = \frac{25}{7}$$ 重点：重新化简三部门乘数公式，推导出含税率 $t$ 的乘数表达式。

(3) $\Delta Y = K_G \times \Delta G = \dfrac{25}{7}\times140 = 500$，故 $\overline{Y}=Y^*+\Delta Y=2500$。
验证：$\{AE=700+0.72Y,\ AE=Y\} \Rightarrow \overline{Y}=2500$。 ✓

例题 10-2 · 两部门经济：消费函数变动对乘数的影响

设某经济中消费函数为 $C=100+0.8Y$，投资 $I=50$。

  1. 求均衡收入、消费和储蓄；
  2. 若当时实际产出为 800，企业非自愿存货积累为多少？
  3. 若投资增至 100，试求增加的收入；
  4. 若消费函数变为 $C=100+0.9Y$，投资仍为 50，收入和储蓄各为多少？收入增加了多少？
  5. 消费函数变动后，乘数有何变化？
解答

(1) $AE=C+I=150+0.8Y$，由 $AE=Y$ 得 $Y^*=750$， $C=100+0.8\times750=700$，$S=-100+0.2\times750=50$。

(2) 当实际产出为 800 时，$AE=150+0.8\times800=790$， 非自愿存货积累 $=$ 实际产出 $-\,AE=800-790=10$。

(3) 投资乘数 $k_1=\dfrac{1}{1-0.8}=5$，$\Delta Y=k_1\times\Delta I=5\times50=250$；投资增至 100 时收入增加 250。

(4) $AE=150+0.9Y$，由 $AE=Y$ 得 $Y^*=1500$，$S=-100+0.1\times1500=50$，$\Delta Y=1500-750=750$。

(5) $k_1=\dfrac{1}{1-0.9}=10$：边际消费倾向由 0.8 上升到 0.9，投资乘数从 5 上升到 10。

第十一章 · 国民收入的决定：IS-LM 模型

本章介绍短期总需求分析的核心内容——IS-LM 模型：在既定不变的物价水平上， 是什么因素决定了总需求水平及其对均衡国民收入的影响，以及是什么因素引起总需求曲线的移动， 从而导致宏观经济的变化。

1. IS 曲线：产品市场均衡

IS 曲线代表产品和服务市场达到均衡（投资 $I$ 与储蓄 $S$ 相等）时，利率与收入的组合轨迹。 两部门经济中总需求等于总供给：$C+I = C+S \Rightarrow I=S$。

设消费函数 $C=\alpha+\beta Y$，两部门均衡收入为：

$$Y = \frac{\alpha+I}{1-\beta}$$

设投资为利率的线性函数 $I=e-dr$（$e$ 为恒定的外生投资，$d$ 为投资需求对利率的反映程度，$r$ 为利率）：

$$Y = \frac{\alpha+e-dr}{1-\beta}$$

2. IS 曲线的推导逻辑

四象限推导的逻辑链：① 利率上升使投资减少（$r$–$I$ 曲线）；② 引起凯恩斯交叉图中计划支出向下移动； ③ 从而引发实际均衡收入的减少；④ 这与 IS 曲线中"利率上升、收入减少"的对应点相吻合—— IS 曲线概括了产品市场均衡的相关变动。

3. IS 曲线的斜率及其变动

$$r = \frac{\alpha+e}{d} - \left[\frac{1-\beta}{d}\right]Y$$

$d$ 代表投资需求对利率的反映程度：$d$ 越大（投资对利率越敏感），IS 曲线越平缓。 $\beta$ 代表边际消费倾向：$\beta$ 越大，$|$斜率$|$ 越小，IS 曲线越平缓 （对应支出乘数 $K_G=\frac{1}{1-\beta}$ 越大）。

  • 投资需求增加 → IS 右移；投资需求下降 → IS 左移
  • 储蓄意愿增加（即投资意愿下降）→ IS 左移
  • 三部门经济中总消费需求变化 → IS 曲线变化
  • 政府支出增加 → IS 右移；税收增加 → IS 左移

4. LM 曲线：货币市场均衡

人们持有/需要货币出于三类动机：① 交易动机；② 预防动机（与收入相关，$L_1=L(Y)=kY$， $k$ 为消费和预防动机所需货币量与实际收入的比例）；③ 投机动机（与利率相关，$L_2=L(r)$）。

凯恩斯陷阱（流动性陷阱）： 利率极高时，投资需求几乎为 0， 人们预期利率不会再升、证券价格不会再跌，因而将货币换为证券；反之，利率极低时， 人们预期利率不会再降、证券只会跌不会涨，因而把证券全部换成货币，此时不再投资、货币不再流动。

货币需求函数（$h$ 为货币需求关于利率变动的系数）：

$$L = L_1+L_2 = kY - hr$$

名义货币需求量需按价格指数 $P$ 折算：$L=L_0/P$，即 $L_0=(kY-hr)P$。

5. LM 曲线的推导

设 $M$ 为实际货币供给量，货币市场均衡：$M=L=kY-hr$，解出 Y-r 关系即为 LM 曲线：

$$Y = \frac{hr}{k}+\frac{M}{k}, \qquad\text{或}\qquad r = \frac{kY}{h}-\frac{M}{h}$$

已知固定的实际货币供给 $\bar M/\bar P$，令需求 $=$ 供给：

$$\frac{\bar M}{\bar P} = kY-hr \ \Longrightarrow\ r = \frac{1}{h}\left(kY-\frac{\bar M}{\bar P}\right)$$

7. IS-LM 模型：产品市场与货币市场的共同均衡

在一个封闭经济体中，边际消费倾向短期内相对稳定，有效需求主要取决于投资， 投资量取决于资本边际效率（MEC）与利率 $r$；而货币供给量 $M$ 和流动性偏好（货币需求 $L$） 又进一步影响利率 $r$。于是商品市场上：收入 $Y$ 依赖于利率 $r$，利率 $r$ 又依赖于收入 $Y$—— 这是一个循环推论问题，因此需要联立 IS 与 LM 两条曲线，共同求解 $r$ 和 $Y$。
例题 11-1 · IS-LM 联立求解

投资函数 $I=1250-250r$，消费函数 $C=500+0.5Y$，储蓄函数 $S=Y-C=-500+0.5Y$； 货币需求 $L=0.5Y+1000-250r$，货币供给 $M=1250$（亿美元）。

解答

由 $I=S$ 得 IS 曲线：$Y=3500-500r$；由 $L=M$ 得 LM 曲线：$Y=500+500r$。

联立求解：$r=3,\ Y=2000$。

一般形式：IS 方程 $I(r)=S(Y)$；LM 方程 $M=L(Y)+L(r)$。由于 $M$ 给定不变， 这是关于 $(r,Y)$ 的二元方程组，解出即得 IS-LM 均衡的一般解。

8. 判断与要点归纳

  • IS 与 LM 交点处：产品供给 = 产品需求；产品市场与货币市场同时均衡；实际货币供给 = 实际货币需求；实际支出 = 意愿支出。
  • IS 曲线斜率取决于：投资需求对利率的反映程度 $d$、边际消费倾向 $\beta$，斜率为 $-\dfrac{1-\beta}{d}$。
  • LM 曲线斜率取决于：货币需求对收入的反应程度 $k$、货币需求对利率的反应程度 $h$，斜率为 $\dfrac{k}{h}$。
  • 其他条件不变时，LM 曲线右移的原因：货币供给量增加；货币交易需求曲线右移。
  • 货币供给和价格水平不变时，收入增加 → 货币需求增加 → 利率上升（由 $kY-hr$ 需保持 $M$ 不变，$Y\uparrow$ 需 $r\uparrow$）。
  • 调整工资不会影响 IS-LM 模型中的 IS 曲线。
  • 按旧传统理论，利率下降时投资不会增加。
  • IS 与 LM 两条曲线不一定总能相交于唯一一点。
例题 11-2 · 投资利率敏感性变化对财政 / 货币政策效果的影响

消费函数 $C=130+0.6Y$，投资函数 $I=750-2000r$，政府购买 $G=750$。

  1. 若投资函数变为 $I=750-3000r$，推导变化前后的 IS 曲线并比较斜率 （两部门经济只需 $I=S$；有政府支出后需考虑 $I+G=S+T$）；
  2. 增加政府购买支出时，比较投资函数变化前后哪种情况收入变化更大；
  3. 增加货币供给时，比较投资函数变化前后哪种情况对收入的影响更大。
解答

(1) 由 $Y=C+I+G=130+0.6Y+750-2000r+750$ 整理，变化前 IS：$r=0.815-0.0002Y$； 变化后（$I=750-3000r$）：$r=0.543-0.000133Y$。比较可知，变化后 IS 曲线斜率变小、更加平缓。

(2) 政府购买支出增加时，IS 右移导致利率上升；投资的利率敏感性增加后，利率上升挤出更多私人投资， 财政政策效果更小，均衡收入增加得较小。

(3) 货币供给增加时，LM 右移导致利率下降；投资利率敏感性增加后，利率下降带来更多私人投资增加， 货币政策效果更大，均衡收入增加得较大。

例题 11-3 · 财政扩张的挤出效应

$Y=C+I+G$，$C=800+0.63Y$，$I=7500-20000r$，货币需求 $L=0.1625Y-10000r$， 名义货币供给 $M=6000$，价格水平 $P=1$。政府购买支出从 7500 增加到 8500，求挤占的私人投资。

解答

$G=7500$ 时：$IS_1: 0.37Y+20000r=15800$；$LM: 0.1625Y-10000r=6000$。 解得 $r_1=0.05,\ Y_1=40000,\ I_1=6500$。

$G=8500$ 时：$IS_2: 0.37Y+20000r=16800$；LM 不变。 解得 $r_2=0.0732,\ Y_2=41438.85,\ I_2=6063$。

挤占的私人投资：$I_2-I_1=6063-6500=-437$（即挤占约 437）。

第十二章 · 国民收入的决定：AD-AS 模型

前述 IS-LM 模型假定一般价格水平不变，这一假设脱离实际。AD-AS 模型进一步引入总需求曲线（AD） 和总供给曲线（AS），分析产量 $Y$ 与价格水平 $P$ 的共同决定。

1. AD 曲线（总需求曲线）

AD 曲线表示在产品市场和货币市场同时达到均衡时，特定价格水平与产出水平的组合， 反映总产量需求与一般价格水平之间的对应关系。

2. 价格水平变动效应

  • 利率效应：价格水平上升 → 名义货币转化的实际货币供给减少 → 利率上升 → 投资和产出反方向变动（收入下降）。
  • 实际余额效应（财富效应）：价格水平变动改变人们所持货币及货币计价资产的实际购买力， 人们相对变富或变穷，消费水平随之增减。
  • 税负 / 名义收入效应：价格水平上升使名义收入增加，可能推高纳税档次、 增加税负，使可支配收入相对下降，进而降低消费水平。

3. AD 曲线的推导

以两部门经济为例：IS 方程 $S(Y)=I(r)$；LM 方程 $\dfrac{M_0}{P}=L(Y)+L(r)$。 将 $Y,r$ 视为未知数、$P$ 视为参数求解，得到的 $Y$-$P$ 关系即为 AD 曲线（只能通过联立方程隐式求解， 但可确定其为减函数）。

推导逻辑：① 价格水平升高（$P\uparrow$）使 LM 曲线截距 $\bar M/(h\bar P)$ 减小，LM 曲线上移； ② 若 IS 不变，均衡收入 $Y$ 减小、利率 $r$ 上升；③ 对应到 AD 曲线（减函数）：收入减少对应价格水平上升。

4. AD 曲线的移动

  • 扩张性财政政策（$G\uparrow$）：$Y=C+I+G=\alpha+\beta(Y-T)+e-dr+G$ 使 IS 右移， 在给定 $P$ 下均衡收入 $Y$ 上升，AD 曲线右移。
  • 扩张性货币政策（给定 $P$ 下 $M\uparrow$）：LM 曲线 $r=\frac{1}{h}(kY-\bar M/\bar P)$ 右移（截距下移），均衡收入 $Y$ 上升，AD 曲线右移。
只要在价格水平 $P$ 不变的情况下，IS-LM 模型中引起总收入水平 $Y$ 变化的因素， 就一定会引起 AD 曲线的移动。

5. AS 曲线（总供给曲线）及其推导

AS 曲线描述总产量与一般价格水平 $P$ 之间的关系，由劳动市场（$N_s$ 劳动供给曲线、$N_d$ 劳动需求曲线， 均衡点 $E$，充分就业实际工资 $W/P_0$、就业量 $N_0$）、生产函数 $Y=F(N)$， 以及 45° 线转换共同决定。

负反馈调节机制：若价格偏离 $P_0$（例如实际状态 $P_1>P_0$，使实际工资 $W/P_1

AS 曲线的移动因素：总供给曲线由生产函数（技术水平、劳动生产率）和劳动市场就业量共同决定。

  • 技术进步 → AS 右移；劳动需求增加 → AS 右移
  • 劳动供给取决于劳动者的意愿偏好与人口 / 劳动力数量：劳动供给增加 → AS 右移；劳动供给减少 → AS 左移

6. 两种特殊的 AS 曲线

7. 三种 AD-AS 模型情形

  1. 极端短期：AS 水平（价格不变），总产量 $Y$ 完全由 AD 决定。
  2. 极端长期（古典情况）：经济达到充分就业，AS 垂直，AD 移动只影响价格水平 $P$，不影响总产量 $Y$。
  3. 一般情况：AS 向右上方倾斜，AD 与 AS 移动都会同时改变总产量 $Y$ 和价格水平 $P$。

8. 判断与要点归纳

  • 物价水平上升 → 实际货币供给减少 → LM 曲线左移。
  • 货币供给量增加 → AD 曲线右移。
  • 经济处于低于充分就业均衡水平时，总需求增加会同时引起物价水平上升和实际国民生产总值增加。
  • 当投资支出对利率比较敏感时，总需求曲线更加平滑（对给定的 LM 移动，Y 反应更大）。
  • 总供给（AS）的决定因素：生产率的变化、资本存量的变化、劳动供给的变化。
  • 总供给曲线：短期斜率为正，长期斜率趋近垂直，萧条区域表现为水平直线（两段式形式）。
  • 总需求（AD）的决定因素：消费者预期的变化、政府支出的变化、利率的变化、税率的变化。
  • 均衡价格发生变动的原因：货币供给变动、市场需求变动、外部供给冲击。
  • 使用扩张性货币政策时，不一定能达到增加国民收入的效果（如处于流动性陷阱或古典区域）。
  • IS-LM 模型说明的总需求对国民收入的作用，与 AD-AS 模型中总需求对国民收入的效果并不相同 （IS-LM 固定价格，AD-AS 允许价格内生变动）。
例题 12-1 · 完整 AD-AS 求解与扩张性货币政策

消费 $C=600+0.8Y$，投资 $I=400-50r$，政府购买 $G=200$；货币需求 $L=250+0.5Y-125r$， 名义货币供给 $M=1250$，价格水平 $P=1$。

  1. 求 IS 方程和 LM 方程；
  2. 求均衡收入和均衡利率；
  3. 充分就业收入为 5000，若用扩张性货币政策实现充分就业，需增加多少货币供给？
  4. 价格水平可变动时，推导总需求函数；
  5. 若总供给函数为 $Y=2375+125P$，求均衡价格水平和均衡收入。
解答

(1) 由产品市场均衡 $Y=C+I+G$ 得 IS：$Y=6000-250r$；由货币市场均衡 $L=M$ 得 LM：$Y=2000+250r$。

(2) 联立解得均衡收入 $Y^*=4000$，均衡利率 $r^*=8$。

(3) 货币政策乘数 $$\frac{\mathrm{d}Y}{\mathrm{d}m} = \frac{1}{(1-0.8)\times\frac{125}{50}+0.5} = 1$$ 充分就业需 $\Delta Y=5000-4000=1000$，因 $P=1$，故 $\Delta M=\Delta m=1000$。

(4) 联立 $Y=6000-250r$ 与 $250+0.5Y-125r=1250/P$，得总需求函数：$Y=2750+\dfrac{1250}{P}$。

(5) 与 $Y=2375+125P$ 联立，解得均衡价格 $P^*=5$，均衡收入 $Y^*=3000$。

例题 12-2 · 财政政策与货币政策实现充分就业的对比

消费 $C=800+0.8Y_d$，税收 $T=0.25Y$，投资 $I=200-50r$，政府购买 $G=200$， 货币需求 $M_d/P=0.4Y-100r$，货币供给 $M_s=900$（名义货币量）， 总供给函数 $Y=2350+400P$。

  1. 求总需求函数；
  2. 已知充分就业收入水平为 2850，判断该经济是否实现充分就业，并给出实现充分就业的政策方案。
解答

(1) $C=800+0.8(Y-0.25Y)=800+0.6Y$，计划支出 $AE=800+0.6Y+200-50r+200=1200+0.6Y-50r$。 由 $AE=Y$ 得 IS：$Y=3000-125r$；由 $L=m$（即 $M_d/P=M_s/P$）得 LM：$Y=\dfrac{2250}{P}+250r$。 联立消去 $r$，得 AD 函数： $$Y = 2000+\frac{750}{P}$$

(2) 与 AS：$Y=2350+400P$ 联立，得 $P=1,\ Y=2750$。由于 $2750<2850$， 经济未实现充分就业，政府应采取扩张性财政或货币政策刺激总需求。 若要实现 $Y=2850$，由 AS 方程反解所需价格： $$P = \frac{2850-2350}{400} = 1.25$$

设政府购买支出为 $G$、货币供应量为 $M$，重新推导一般化 IS/LM/AD：

产品市场：$Y=C+I+G=1000+0.6Y-50r+G \Rightarrow Y=2500-125r+2.5G$

货币市场：$0.4Y-100r=M/P \Rightarrow Y=\dfrac{2.5M}{P}+250r$

联立得一般 AD 函数：$$Y = \frac{5000}{3}+\frac{5}{3}G+\frac{2.5}{3}\cdot\frac{M}{P}$$

a) 仅用扩张性财政政策（$M=900$ 不变），令 $Y=2850,\ P=1.25$： $$G = \frac{3}{5}\left(2850-\frac{5000}{3}-\frac{2.5}{3}\times\frac{900}{1.25}\right)=350,\qquad \Delta G = 350-200=150$$ 即政府购买增加 150，可实现充分就业。

b) 仅用扩张性货币政策（$G=200$ 不变），令 $Y=2850,\ P=1.25$： $$M = \frac{3}{2.5}\times1.25\times\left(2850-\frac{5000}{3}-\frac{5}{3}\times200\right)=1275,\qquad \Delta M = 1275-900=375$$ 即货币供给增加 375，可实现充分就业。
