ECG 762 HW3 — CRLB for the Bivariate Gaussian Correlation Coefficient and Feasibility of a Line-Array Bearing Estimator

Two estimation-theory problems (Kay, Ch. 3): (1) the CRLB for the correlation coefficient $\rho$ of independent bivariate Gaussian samples with covariance $\mathbf{C}=\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix}$, derived from the general Gaussian Fisher-information formula (3.32); (2) a bearing-estimation feasibility study for a $\lambda/2$-spaced line array at 1 MHz — using the CRLB for the bearing $\beta$ (Example 3.15, Eq. 3.43) to determine the minimum number of antenna elements needed for a $5^\circ$ standard deviation at broadside with 0 dB SNR, and assessing whether the resulting array is practical for aircraft-wing mounting.

Problem 1 (3.15)

Independent bivariate Gaussian samples $\{\mathbf{x}[0],\mathbf{x}[1],\ldots, \mathbf{x}[N-1]\}$ are observed. Each observation is a $2\times1$ vector distributed as $\mathbf{x}[n]\sim\mathcal N(\mathbf 0,\mathbf C)$ with $\mathbf{C}=\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix}$. Find the CRLB for the correlation coefficient $\rho$. Hint: use (3.32),

$$I(\theta)=\left[\frac{\partial\boldsymbol\mu(\theta)}{\partial\theta}\right]^T\mathbf{C}^{-1}(\theta) \left[\frac{\partial\boldsymbol\mu(\theta)}{\partial\theta}\right] + \frac12\operatorname{tr}\!\left[\left(\mathbf{C}^{-1}(\theta)\frac{\partial\mathbf{C}(\theta)}{\partial\theta}\right)^2\right].$$
SOLUTION

Each observation is distributed as

$$\mathbf{x}[n]\sim\mathcal N(\mathbf 0,\mathbf C), \qquad \mathbf{C}=\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix}, \qquad |\rho|<1.$$

Since the mean vector does not depend on $\rho$, $\partial\boldsymbol\mu/\partial\rho=\mathbf 0$, and the first term of (3.32) vanishes. Therefore, the Fisher information from a single observation reduces to

$$I_1(\rho)=\frac12\operatorname{tr}\!\left[\left(\mathbf{C}^{-1}\frac{\partial\mathbf{C}}{\partial\rho}\right)^2\right].$$

The inverse covariance matrix and its derivative with respect to $\rho$ are

$$\mathbf{C}^{-1}=\frac{1}{1-\rho^2}\begin{bmatrix}1&-\rho\\-\rho&1\end{bmatrix}, \qquad \frac{\partial\mathbf{C}}{\partial\rho}=\begin{bmatrix}0&1\\1&0\end{bmatrix}.$$

Multiplying these together,

$$\mathbf{C}^{-1}\frac{\partial\mathbf{C}}{\partial\rho} = \frac{1}{1-\rho^2}\begin{bmatrix}-\rho&1\\1&-\rho\end{bmatrix},$$

and squaring,

$$\left(\mathbf{C}^{-1}\frac{\partial\mathbf{C}}{\partial\rho}\right)^2 = \frac{1}{(1-\rho^2)^2}\begin{bmatrix}1+\rho^2&-2\rho\\-2\rho&1+\rho^2\end{bmatrix}.$$

Taking the trace gives

$$I_1(\rho)=\frac12\cdot\frac{2(1+\rho^2)}{(1-\rho^2)^2}=\frac{1+\rho^2}{(1-\rho^2)^2}.$$

Because the $N$ observations are independent, their Fisher information adds:

$$I_N(\rho)=N\,I_1(\rho)=\frac{N(1+\rho^2)}{(1-\rho^2)^2}.$$
CRLB $$\operatorname{var}(\hat\rho)\ge\frac{1}{I_N(\rho)}=\frac{(1-\rho^2)^2}{N(1+\rho^2)}, \qquad |\rho|<1.$$

Problem 2 (3.19)

A line array of antennas with $d=\lambda/2$ spacing for a 1 MHz electromagnetic signal is to be designed to yield a $5^\circ$ standard deviation at $\beta=90^\circ$. If the SNR $\eta$ is 0 dB, comment on the feasibility of the requirement. Assume the line array is to be mounted on the wing of an aircraft. Use $c=3\times10^8$ m/s.

SOLUTION

Let $M$ denote the number of antenna elements. From the bearing-estimation result in Example 3.15, Eq. (3.43), the CRLB is

$$\operatorname{var}(\hat\beta)\ge \frac{12}{\eta M(M^2-1)\left(\dfrac{2\pi d}{\lambda}\right)^2\sin^2\beta},$$

where $\beta$ is measured in radians and $\eta$ is the linear SNR. For a 1 MHz electromagnetic signal, the wavelength is

$$\lambda=\frac{c}{f}=\frac{3\times10^8}{1\times10^6}=300\text{ m}.$$

Therefore, the required element spacing is

$$d=\frac{\lambda}{2}=150\text{ m}.$$

Since

$$\eta=10^{0/10}=1, \qquad \sin^2 90^\circ=1, \qquad \frac{2\pi d}{\lambda}=\pi,$$

the bound reduces to

$$\operatorname{var}(\hat\beta)\ge\frac{12}{\pi^2 M(M^2-1)}.$$

The desired standard deviation, expressed in radians, is

$$\sigma_{\text{target}}=5\cdot\frac{\pi}{180}=\frac{\pi}{36}\approx0.08727\text{ rad}.$$

A necessary condition for meeting this requirement is that the CRLB not exceed the target variance,

$$\frac{12}{\pi^2 M(M^2-1)}\le\left(\frac{\pi}{36}\right)^2.$$

Rearranging gives

$$M(M^2-1)\ge\frac{15552}{\pi^4}\approx159.66.$$

For $M=5$, $M(M^2-1)=5(25-1)=120$, which does not satisfy the condition. For $M=6$, $M(M^2-1)=6(36-1)=210$, which satisfies it.

Result The CRLB requires at least six antenna elements. The corresponding array length is $$L=(M-1)d=(6-1)(150)=750\text{ m}.$$
The requirement is impractical for an array mounted on an aircraft wing: even the idealized CRLB calculation requires a 750 m array. Moreover, satisfying the CRLB condition is necessary but does not guarantee that a practical estimator will achieve the desired standard deviation.
